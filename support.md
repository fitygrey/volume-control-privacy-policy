# Volume Control 技术支持

如果 Volume Control 无法控制外接显示器音量，请先检查：

1. 在 macOS“系统设置”中允许 Volume Control 使用系统音频录制权限；
2. 在菜单栏中点击刷新，并确认选择了正确的输出设备；
3. 使用菜单栏中的主音量滑块或静音按钮测试控制。

如需使用键盘音量键或音量滚轮，请在应用的“首次设置”或“设置 → 常规 → 键盘音量控制”中主动点击允许，然后在 macOS“系统设置 → 隐私与安全性 → 输入监控”中启用 Volume Control。该权限为可选权限；应用只读取音量增加、音量减少和静音事件。

如问题仍未解决，请在应用的“设置 → 诊断”中复制诊断信息，并发送至：

[onebooksoftware@outlook.com](mailto:onebooksoftware@outlook.com)

诊断信息不会自动上传，只有在您主动发送时我们才会收到。

# Volume Control Support

If Volume Control cannot control the volume of an external display:

1. Allow Volume Control to use System Audio Recording in macOS System Settings;
2. Click Refresh in the menu bar and confirm that the correct output device is selected;
3. Test control with the master-volume slider or mute button in the menu bar.

To use keyboard volume keys or a volume wheel, choose Allow in **First Setup** or **Settings → General → Keyboard Volume Control**, then enable Volume Control in **macOS System Settings → Privacy & Security → Input Monitoring**. This permission is optional; the App reads only volume-up, volume-down, and mute events.

If the issue continues, copy the diagnostic information from **Settings → Diagnostics** and email it to:

[onebooksoftware@outlook.com](mailto:onebooksoftware@outlook.com)

Diagnostics are never uploaded automatically. We receive them only when you choose to send them.
